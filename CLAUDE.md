# Роль & Инструкции для Claude Code (MeDev)

Прочитай этот файл перед тем как вносить любые изменения в проект MeDev.

## Общий Контекст
- **Стек:** Spring Boot 3.3.0, Java 17, PostgreSQL, React 19, TypeScript, FSD, Tailwind v4.
- **Архитектура:** Модульный монолит на бэкенде. Feature-Sliced Design на фронтенде.
- **Безопасность (Приоритет №1):** Защита от IDOR критична. Всегда используй `SecurityUtils.getCurrentUserId()` для проверок. Секреты только в переменных окружения.
- **Дизайн:** Строгий GitHub Dark Mode (`#0d1117` bg, `#161b22` cards). Никакого Glassmorphism.

## Протокол Действий (Workflow)
1. **Сначала Теория:** Перед написанием кода, сформулируй архитектурный подход и трейд-оффы.
2. **Зелёные тесты:** Никогда не делай push, если есть ошибки или падающие тесты.
3. **Журнал:** После успешного прохождения тестов, обязательно сделай запись в `journal/YYYY-MM-DD/` перед тем как делать `git push`. Это правило подкреплено git-хуком `pre-push`.
4. **БД Миграции:** Никогда не модифицируй существующие скрипты в `db/migration/`. Все изменения БД — это новые скрипты `V{N}__`.

## Ограничения
- Не предлагай Docker без явного запроса.
- Экономия токенов: избегай долгих лупов, не читай весь проект подряд без нужды. Выполняй точечные изменения.
