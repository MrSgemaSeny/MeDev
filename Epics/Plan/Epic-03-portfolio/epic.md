## Зачем этот эпик

Публичная веб-страница портфолио — первый артефакт, который видит рекрутер. Без этого эпика профиль нельзя показать по URL без авторизации.

## Пользовательские истории

| ID | Роль | Хочу | Чтобы | Статус |
|---|---|---|---|---|
| US-03.1 | Гость | открыть портфолио по `/portfolio/{username}` без авторизации | посмотреть профиль кандидата | Done |

| US-03.4 | Гость | не получить leak факта существования приватного профиля | не существовало leak | Done |

## Out of Scope

- Скачивание PDF из портфолио — Epic-06

---

## Технические решения

- **Privacy-by-default через 404** — приватный профиль возвращает 404 (не 403), не раскрывает факт существования.
- **`PublicProfileDto`** — отдельный DTO без служебных полей.
- **`PortfolioMapper` (MapStruct, reuses ProfileMapper)** — переиспользование маппинга секций.
