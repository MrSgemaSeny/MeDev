# MeDev (DevProfile) — Стратегический Roadmap и Спринты

Этот документ фиксирует текущий вектор развития проекта MeDev, нерешенные проблемы архитектуры (техдолг) и пошаговый план по выводу проекта в production-ready состояние.

---

## 🎯 Глобальный статус
- **Фаза:** Переходная (Фаза 3 завершена, но выявлен критический техдолг перед Фазой 4).
- **Дизайн:** Успешно переведен на строгий **GitHub Dark Mode** (без Glassmorphism, компактные панели).
- **Главный блокер:** Отсутствие тестов, CI/CD и монолитный `ProfileService`, который мешает безопасно внедрять Stripe (Фаза 4).

---

## 🛑 Критический Техдолг (К исправлению)

### 1. Архитектура Бэкенда
- **ProfileService God Object (472 строки)**: Сейчас один сервис отвечает за CRUD 6 разных сущностей (Experience, Education, Skills, Languages, Projects) и GitHub импорт.
- **Маппинг**: 6 ручных методов `mapToXxxDto`. Необходимо внедрить **MapStruct**.
- **GroqClient**: Синхронный, без таймаутов, без ретраев (нет защиты от 503 от Groq).
- **AI Валидация**: Нет fallback на случай, если LLM вернет сломанный JSON.
- **Глобальные ошибки**: `GlobalExceptionHandler` не обрабатывает ошибки валидации (`@Valid`) и лимиты файлов (`MaxUploadSizeExceeded`).

### 2. Инфраструктура и Безопасность
- **Тесты**: 0% покрытия. Необходимы JUnit 5 + Mockito + TestContainers.
- **CI/CD**: Отсутствует автоматическая проверка сборки и тестов при пуше (нужен GitHub Actions).
- **Деплой**: Нет `fly.toml` и `Dockerfile` для выкатки бэкенда.
- **Rate Limiting**: Нет защиты от спама на эндпоинты авторизации и ИИ (нужен Bucket4j).
- **CORS**: Wildcard `*` в конфигурации нужно заменить на строгие origin'ы для продакшена.

### 3. Фронтенд
- **Производительность**: Нет Code Splitting. Весь React-апп грузится одним бандлом (нужен `React.lazy`).
- **Авторизация**: Axios interceptor не умеет делать автоматический refresh токена при получении 401 ошибки.
- **Локализация (i18n)**: Переведен только `ResumeBuilder`, остальные страницы (Dashboard, Login) захардкожены на английском.
- **Архитектура**: FSD (Feature-Sliced Design) внедрен частично, некоторые папки пустуют или логика смешана.

## 🏃‍♂️ План Спринтов

### Sprint 1: Инфраструктура, Безопасность и Фронт-косметика
*Цель: Закрыть дыры, которые мешают нормально работать с кодом и защитить API.*
- [ ] Настроить GitHub Actions (CI пайплайн: build, test).
- [ ] Внедрить лимит на загрузку PDF (`max-file-size: 10MB`).
- [ ] Реализовать обработку `MethodArgumentNotValidException` в `GlobalExceptionHandler`.
- [ ] Написать Unit-тесты на базовые сервисы: `AuthService` и `JwtService`.
- [ ] Добавить ленивую загрузку (Code Splitting) маршрутов на фронтенде.

### Sprint 2: Распил Монолита и Стабильность AI
*Цель: Очистить ядро бизнес-логики и сделать ИИ-интеграцию отказоустойчивой.*
- [ ] Разбить `ProfileService` на 6 независимых сервисов.
- [ ] Внедрить `MapStruct` вместо ручного маппинга DTO.
- [ ] Переписать `GroqClient`: добавить таймауты (30s/60s) и ретраи с exponential backoff.
- [ ] Добавить безопасный try-catch парсинг ответов от Groq с fallback логикой.
- [ ] Фронт: Реализовать Axios Refresh Token Interceptor (обновление токена в фоне).

### Sprint 3: Подготовка к Продакшену
*Цель: Подготовить проект к безопасному публичному релизу.*
- [ ] Внедрить Bucket4j (Rate Limiting) на Auth и AI эндпоинты.
- [ ] Написать `Dockerfile` и `fly.toml` для бэкенда.
- [ ] Завершить локализацию (i18n) на всех страницах фронтенда.
- [ ] Строгая настройка CORS для продакшен доменов.
- [ ] Добавить JSON-структурированное логирование (MDC + logback-spring.xml).
